# 숫자 야구 대전

중학생용 숫자 야구 대전 웹 게임입니다. 학생마다 자기 기기로 접속해서 1:1로 대전합니다.

- **학생용**: `index.html`
- **교사용**: `teacher.html` (전적 확인, 모든 학생 화면 멈추기)

## 난이도

| 단계 | 숫자 | 자릿수 | 힌트 |
|---|---|---|---|
| 하 | 1~6 | 2자리 | 자리마다 ○ △ × |
| 중 | 1~9 | 3자리 | 자리마다 ○ △ × |
| 중상 | 1~6 | 3자리 | 스트라이크(S)·볼(B) 개수만 |
| 상 | 0~9 | 3자리 | 스트라이크(S)·볼(B) 개수만 |

두 사람이 동시에 한 번씩 추측하고 결과가 같이 공개됩니다. 같은 회에 둘 다 맞히면 무승부, 10회 안에 아무도 못 맞혀도 무승부입니다.

## 수업에서 쓰는 순서

1. 교사가 `teacher.html`을 열면 수업 코드 4자리가 나옵니다. 수업이 끝날 때까지 이 창을 열어 두세요.
2. **학생용 주소 복사**로 복사한 주소를 학생들에게 나눠 줍니다. (주소에 수업 코드가 들어 있어요)
3. 학생은 이름을 넣고 **연결**을 누릅니다. 수업에 연결되기 전에는 아무 버튼도 열리지 않아요. 연결한 뒤 한 명은 **방 만들기**, 상대는 **방 들어가기**로 방 코드를 입력합니다.
4. 온라인 대전이 끝나면 결과가 교사용 페이지에 자동으로 쌓입니다.
5. **모든 학생 화면 멈추기**를 누르면 연결된 학생 화면이 모두 멈춥니다.
6. **인터넷 없이 하기**는 처음에 잠겨 있어요. 교사용 페이지에서 **허용하기**를 누르면 연결된 학생들에게 열리고, **다시 잠그기**를 누르면 그 모드를 쓰던 학생도 처음 화면으로 돌아갑니다.

수업 중에 교사용 페이지와 연결이 끊기면 학생 화면은 3초 뒤 잠기고, 다시 연결되면 풀립니다. 단, 허용받은 **인터넷 없이 하기**는 연결이 끊겨도 3시간 동안 계속 쓸 수 있어요.

## 🎬 시연 (선생님 vs 컴퓨터)

교사용 페이지의 **🎬 시연** 버튼(또는 학생용 주소 뒤에 `?demo=1`)을 누르면 새 탭에 프로젝터용 시연 화면이 열립니다. 수업 연결 없이 동작해요.

- 선생님이 비밀 숫자를 정하고(●로 가려짐) 컴퓨터와 동시에 추측하며 대결합니다.
- 위쪽 **코치 말풍선**이 단계마다 사용법을 안내합니다: 비밀 숫자 정하기 → 대결 시작 → 첫 결과 읽는 법(실제 결과로 숫자별 설명) → 컴퓨터는 어떻게 추리할까 → 좋은 추측이란.
- 오른쪽 **💭 컴퓨터의 생각**에서 컴퓨터가 후보를 지워 가는 과정(남은 경우의 수)을 보여 줍니다. 하 단계는 6×6 표, 3자리 단계는 60가지 이하일 때 목록.
- 컴퓨터 실력: 약함(아무 숫자나) · 보통(가능한 숫자 중에서) · 강함(가장 잘 줄이는 숫자)
- 경기 후 복기에서 선생님과 컴퓨터가 후보를 줄인 과정을 나란히 비교합니다.

## 경우의 수 수업 기능

- **예측 퀴즈**: 교사용 페이지에서 문제를 고르고 [퀴즈 내기]를 누르면 학생 화면에 문제가 뜹니다. 학생 답이 교사 화면에 분포로 모이고, [정답 공개]를 누르면 학생 화면에 정답과 풀이가 나옵니다. 준비된 문제: 30(하) · 120(중상) · 504(중) · 720(상) · 648(맨 앞 0 금지) · 36(같은 숫자 허용), 직접 입력도 가능.
- **게임 상황 퀴즈**: 퀴즈 칸에서 [⚾ 게임 상황 문제]를 고르면, 단계와 추측·결과 줄을 넣어 “이 상황에서 가능한 비밀 숫자는 몇 가지?” 또는 “비밀 숫자는 무엇일까?”를 낼 수 있어요. 🎲 버튼은 실제 비밀 숫자로 진짜 결과를 만들어 줘요. 정답은 자동 계산되고, 정답 공개 때 가능한 숫자 목록이 학생 화면에 함께 나와요. 프로젝터에 띄울 때는 [📺 화면 띄우기 모드]를 켜면 학생 이름과 정답이 가려져요.
- **남은 경우의 수**: 교사가 [보이기]를 누르면 학생 화면에 회마다 “남은 경우의 수 504 → 60가지”가 나옵니다. (처음에는 숨김)
- **복기**: 경기가 끝나면 결과 창의 [📉 복기]에서 회차별로 경우의 수가 줄어든 막대와, 남은 후보 중 가장 잘 줄이는 추측 예시를 보여 줍니다.
- **후보 표**: 하 단계(2자리)에서는 6×6 표(같은 숫자 칸은 빗금)에 30가지 후보가 나오고, 학생이 직접 지워 가며 추리합니다.

## 화면 기능

- 학생: 두 사람이 냈는지 여부 표시, 방금 끝난 회의 결과 크게 보기, 같은 숫자 다시 추측하면 경고, 메모판(접기 가능), 경기 끝나면 상대 숫자 공개
- 교사: 📺 크게 보기(프로젝터용 수업 코드), 전적 오늘/전체 전환, 학생별 진행 회차 표시

## 참고

- 서버 없이 기기끼리 직접 연결하는 방식(WebRTC, PeerJS)입니다. 학교 와이파이가 이런 연결을 막으면 연결되지 않을 수 있어요. 그럴 때는 **인터넷 없이 하기** 모드를 쓰면 됩니다.
- 전적 기록은 교사용 페이지를 연 브라우저에만 저장됩니다. 필요하면 CSV로 내려받으세요.
- 비밀 숫자는 학생 기기 밖으로 나가지 않습니다. 상대의 추측을 받으면 내 기기가 판정해서 결과만 보냅니다.
